❓ Aide — Titimessenger

Titimessenger permet d'envoyer un message chiffré à quelqu'un sans compte ni serveur : le message chiffré est encodé directement dans un lien ou un QR code.

🔑 La clé

  • Choisissez une clé secrète et communiquez-la à votre destinataire séparément du lien (de vive voix, idéalement) — jamais dans le même message.
  • Le bouton 🙈/👁️ affiche ou masque la clé à l'écran.

✏️ Écrire un message

  • 🔒 Chiffrer : chiffre votre message avec la clé.
  • 🔐 Cadenas : chiffre le message deux fois de suite, pour une protection renforcée.
  • Un lien est alors généré : envoyez-le par WhatsApp, Telegram, SMS, e-mail, ou via le QR code.

📱 QR code

  • Générer un QR code crée une image qui ouvre directement Titimessenger avec le message déjà chargé — pratique en face à face, il suffit de le scanner puis de taper la clé.
  • Le texte codé est placé après le # du lien : il n'est jamais envoyé à un serveur, tout reste entre les deux appareils.

📩 Recevoir un message

  • En ouvrant le lien reçu (ou en scannant le QR code), Titimessenger s'ouvre directement en mode réception.
  • Entrez la clé secrète, cliquez sur Déchiffrer, et le message apparaît en clair.
  • ↩️ Répondre permet d'écrire une réponse avec la même clé déjà pré-remplie.

🔐 Bon à savoir

  • Tout le chiffrement se fait dans votre navigateur : rien n'est envoyé sur Internet, aucun message n'est stocké nulle part.
  • Sans la bonne clé, impossible de relire le message — conservez-la précieusement.
  • ⚠️ Pour que le lien/QR code fonctionne pour quelqu'un d'autre, cette page doit être hébergée en ligne (une vraie adresse https://...), pas ouverte comme simple fichier local.
